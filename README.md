# Logic Questions on Arrays

Small C exercises covering array logic.

| File | Topic |
| --- | --- |
| `finding_element.c` | locating an element in an array |
| `input_string.c` | string input handling |

## Build

```bash
gcc finding_element.c -o finding_element
gcc input_string.c -o input_string
```

## Notes

No headers, no build system, no tests - these are standalone exercises, one
problem per file.
